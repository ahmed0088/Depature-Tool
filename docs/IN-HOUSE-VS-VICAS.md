# In House vs Vicas

Immigration Check page: add the Opera immigration report and the Vicas Inhouse file. The card "In House vs Vicas" compares them room by room.

- Matched: same room and a shared name word (any order, titles ignored).
- Names differ: same room, nobody left to pair with by name.
- Only in the Opera report / only in the Vicas list: nobody on the other side in that room.
- Rooms with no number or 8000 and up (POS and house accounts) are left out.

Read only. Nothing is saved or sent. Names are shown on screen only and never stored.
